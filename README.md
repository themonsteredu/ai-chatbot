# AI WEB APP LAB

중학생이 App Inventor처럼 부품을 놓고, 속성을 바꾸고, 블록으로 동작을 만들어
`나만의 웹앱`을 완성하는 교육용 제작 도구입니다. 첫 화면은 아무것도 놓이지 않은
빈 웹앱이며, 필요한 부품을 원하는 만큼 놓아 조합할 수 있습니다.

## 제작 구조

- **시작 예시**: 빈 웹앱, 3일 캠프 기록, 우리 반 알림장
- **팔레트**: 네 갈래로 나뉜 부품 16종
  - *기본* — 글자, 사진, 버튼, 구분선, 목록
  - *입력* — 입력창, 체크박스, 스위치, 슬라이더
  - *배치* — 가로 배치, 세로 배치 (안에 다른 부품을 넣습니다)
  - *웹앱 기능* — 안내 카드, 활동 체크, 나의 기록, 3일 캠프 기록, 나만의 챗봇
- **컴포넌트**: Screen1 아래 부품을 트리로 확인. 같은 부품을 여러 개 놓을 수 있고
  이름도 바꿀 수 있습니다 (버튼1, 버튼2 …)
- **속성**: 부품마다 내용·꾸미기·동작으로 나뉩니다. 글자 크기, 굵기, 글자색,
  배경색, 정렬, 여백, 너비, 보이기는 모든 부품이 함께 가집니다
- **뷰어**: 오른쪽에는 만든 화면만 놓입니다

만드는 일(팔레트·컴포넌트·속성)은 **모두 왼쪽 판 한 곳**에 모여 있습니다. 부품을
누르는 곳과 그 부품을 고치는 곳이 붙어 있어야, 색 하나 바꾸자고 화면을 가로지르지
않습니다. 좁은 화면에서는 `만들기` / `화면` 두 칸으로 나뉩니다.
- **블록**: 학생이 직접 `언제 무엇을 할지`를 조립합니다
- **되돌리기**: `Ctrl+Z` / `Ctrl+Shift+Z`
- **실행**: 완성한 웹앱을 실제로 사용하고 휴대폰 홈 화면에 설치

## 블록

이벤트 하나를 고르면 스택이 생기고, 그 아래에 동작을 이어 붙입니다.

- **이벤트** — 화면을 열었을 때, 버튼을 클릭했을 때, 입력창·체크박스·스위치·
  슬라이더의 값이 바뀌었을 때, 활동을 체크했을 때, 기록을 저장했을 때,
  캠프 차시를 저장했을 때, 보고서를 인쇄했을 때, 챗봇에 질문했을 때
- **동작** — 부품 바꾸기, 말풍선 보여 주기, 변수 정하기, 만약 ~라면, 반복하기
- **값** — 글자, 숫자, 참·거짓, 변수, 다른 부품의 값, 계산, 비교, 이어 붙이기

값을 넣는 구멍은 모두 **고르는 칸**이라, 말이 안 되는 프로그램은 만들어지지
않습니다. 변수·조건·반복은 `더 보기`를 켜야 나오므로 처음 배우는 어휘는 작게
유지됩니다. 블록이 너무 오래 돌면 브라우저가 멈추는 대신 안내를 띄우고 멈춥니다.

예: `버튼1을 클릭했을 때 → 글자1의 보여 줄 글을 "안녕!"으로 바꾸기`

## 3일 캠프 기록

하루 4차시씩 총 12차시의 배운 내용과 활동, 사진, 느낀 점을 기록합니다.
3일차에는 전체 소감을 작성하고 A4 활동 보고서로 인쇄할 수 있습니다.
글과 압축된 사진은 서버가 아니라 사용하는 기기의 브라우저 저장 공간에
자동 저장됩니다. 저장 자리는 웹앱마다 따로 있어서, 프로젝트 이름을 바꾸거나
같은 예제로 웹앱을 여러 개 만들어도 기록이 섞이지 않습니다.

## 나만의 챗봇

학생이 직접 질문과 답을 추가합니다. 실행 중에는 등록된 질문과 겹치는 낱말이
가장 많은 답을 보여 주며, 하나도 겹치지 않으면 학생이 설정한 안내 문구를
보여 줍니다. 외부 생성형 AI API는 사용하지 않습니다.

## 예전 프로젝트

기능 여섯 가지를 켜고 끄던 시절(v3)에 저장한 프로젝트도 그대로 열립니다.
열 때 부품 트리로 옮겨지고, 코드에 박혀 있던 버튼 동작은 학생이 고칠 수 있는
진짜 블록이 됩니다. 꺼 두었던 기능은 지워지지 않고 `보이기`만 꺼진 채로
남습니다.

## 로컬 실행

Node.js 22.13 이상이 필요합니다.

```bash
npm install
npm run dev
```

검증:

```bash
npm run lint
npm test
```

`npm test`는 `next build` 뒤에 `node --test`를 돌립니다. 프로젝트 마이그레이션,
주소 인코딩, 블록 해석기, 부품 사전은 실제 모듈을 불러와 시험합니다.

## 배포 환경 변수

기본 배포 대상은 Vercel입니다.

| 변수 | 쓰임 |
| --- | --- |
| `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY` | 반 제출·공유 코드 저장소 |
| `TEACHER_ADMIN_CODE` 또는 `TEACHER_INSTRUCTOR_CODE` | 교사용 명단·기록 조회. **둘 다 없으면 교사용 요청을 받지 않습니다.** 학생 이름과 사진이 오가는 곳이라 널리 알려진 기본값으로 열리지 않습니다 |
| `NEXT_PUBLIC_VERCEL_PROJECT_PRODUCTION_URL` | 공유 링크·QR을 공개 주소로 만듭니다 |
