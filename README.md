# AI WEB APP LAB

중학생이 App Inventor처럼 기능을 고르고 속성을 바꾸며 `나만의 웹앱`을
만드는 교육용 제작 도구입니다. 첫 화면은 아무 기능도 없는 빈 웹앱이며,
활동 기록장·알림장·학생 제작형 챗봇을 원하는 만큼 조합할 수 있습니다.

## 제작 구조

- **시작 예시**: 빈 웹앱, 3일 캠프 기록, 우리 반 알림장
- **팔레트**: 안내 카드, 활동 체크, 나의 기록, 3일 캠프 기록, 일반 버튼, 나만의 챗봇
- **뷰어**: 휴대폰 화면에서 웹앱 전체 구성과 결과를 바로 확인
- **컴포넌트**: Screen1 아래 구성 요소를 한눈에 확인
- **속성**: 제목, 안내, 체크 항목, 기록 문구, 캠프 질문, 버튼 동작, 챗봇 질문·답 편집
- **블록**: 자동 저장, 보고서 인쇄, 버튼, 챗봇의 동작 확인
- **실행**: 완성한 웹앱을 실제로 사용하고 휴대폰 홈 화면에 설치

## 3일 캠프 기록

하루 4차시씩 총 12차시의 배운 내용과 활동, 사진, 느낀 점을 기록합니다.
3일차에는 전체 소감을 작성하고 A4 활동 보고서로 인쇄할 수 있습니다.
글과 압축된 사진은 서버가 아니라 사용하는 기기의 브라우저 저장 공간에
자동 저장됩니다.

## 나만의 챗봇

학생이 직접 질문과 답을 추가합니다. 실행 중에는 등록된 질문과 비슷한
문장을 찾아 그 답만 보여 주며, 답을 찾지 못하면 학생이 설정한 안내
문구를 보여 줍니다. 외부 생성형 AI API는 사용하지 않습니다.

## 로컬 실행

Node.js 22.13 이상이 필요합니다.

```bash
npm install
npm run dev
```

검증:

```bash
npm run lint
npm test
```

기본 배포 대상은 Vercel입니다.
