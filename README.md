# 챗봇 메이커

학생 누구나 코딩 없이 템플릿과 기능 블록을 조합해 자신만의 챗봇을
만들고 공유할 수 있는 노코드 제작 스튜디오입니다.

## 주요 기능

- 빈 챗봇, AI 캠프, 학급 알림, 독서 활동 템플릿
- 챗봇 이름, 캐릭터, 소개, 첫 인사, 대표 색상 편집
- 안내, 기록, 체크리스트, 일정, 질문 답변, 선택 기능 블록
- 기능 내용 편집, 순서 변경, 삭제
- 휴대폰 형태의 실시간 대화 미리보기
- 브라우저 자동 저장 및 URL 기반 공유
- 데스크톱과 모바일 반응형 UI

현재 버전은 별도 회원가입이나 서버 데이터베이스 없이 브라우저에
프로젝트를 저장합니다. 공유 링크에는 챗봇 설정이 포함되며 개인정보나
비밀 정보를 입력하지 않는 것을 권장합니다.

## 로컬 실행

Node.js 22.13 이상이 필요합니다.

```bash
npm install
npm run dev
```

검증용 빌드와 테스트:

```bash
npm test
```
