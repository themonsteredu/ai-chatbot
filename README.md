# AI 챗봇 LAB

초등 3~6학년과 중학생이 App Inventor처럼 기능을 고르고 속성을 바꾸며
`AI 알림장 챗봇`을 만드는 교육용 웹 제작 도구입니다.

## 제작 구조

- **팔레트**: 화면 배경, 챗봇 머리글, 첫 인사, 질문 버튼, 입력창
- **뷰어**: 휴대폰 화면에서 배치와 결과를 바로 확인
- **컴포넌트**: Screen1 아래 구성 요소를 한눈에 확인
- **속성**: 버튼 글, 챗봇 답, 대표 색, 안내 문구 편집
- **블록**: `버튼을 클릭했을 때 → 챗봇이 말하기` 연결 확인
- **실행**: 질문 버튼과 직접 입력을 실제 챗봇처럼 테스트

기본 예제에는 `오늘 숙제`, `내일 준비물`, `부모님께 전달할 말`,
`오늘 배운 것`, `오늘의 소감` 질문 버튼이 들어 있습니다. 프로젝트는
브라우저에 자동 저장되며, 설정이 포함된 링크로 공유할 수 있습니다.

## 로컬 실행

Node.js 22.13 이상이 필요합니다.

```bash
npm install
npm run dev
```

검증:

```bash
npm run lint
npm test
```

기본 배포 대상은 Vercel입니다.
