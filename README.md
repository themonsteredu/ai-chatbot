# 나만의 웹 만들기

학생들이 기획부터 화면 구성, 기능 연결, 테스트까지 앱 인벤터처럼 블록을
조립해 자신만의 웹을 만들고 공유하는 교육용 제작 스튜디오입니다.
첫 번째 수업용 템플릿은 AI 캠프 기록장입니다.

## 주요 기능

- 캠프 기록장, 독서 기록장, 우리 반 알림장, 빈 웹 템플릿
- 주제, 사용자, 목적을 정리하는 웹 기획서
- 첫 화면, 글, 알림, 일정, 사진 모음 화면 블록
- 기록 입력, 미션 체크, 이동 버튼, 자유 기능 블록
- 블록 내용 편집, 드래그 순서 변경, 삭제
- 색상, 배경, 카드 모서리, 글자 크기, 열 배치 편집
- 실제 입력과 저장을 시험하는 반응형 웹 미리보기
- 브라우저 자동 저장 및 URL 기반 프로젝트 공유

현재 버전은 별도 회원가입이나 서버 데이터베이스 없이 브라우저에
프로젝트와 미리보기 기록을 저장합니다. 공유 링크에는 웹 프로젝트 설정이
포함되며 개인정보나 비밀 정보를 입력하지 않는 것을 권장합니다.

## 로컬 실행

Node.js 22.13 이상이 필요합니다.

```bash
npm install
npm run dev
```

검증용 빌드와 테스트:

```bash
npm test
```

## 배포

이 프로젝트의 기본 배포 대상은 Vercel입니다. GitHub의 `main` 브랜치와
Vercel 프로젝트를 연결하면 이후 변경 사항도 자동으로 운영 환경에
배포할 수 있습니다.
