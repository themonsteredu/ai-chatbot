# AI WEB APP LAB

학생이 App Inventor처럼 기능을 고르고 속성을 바꾸며 `나만의 웹앱`을
만드는 교육용 웹 제작 도구입니다. 챗봇은 웹앱 안에 넣을 수 있는 여러
기능 중 하나입니다.

## 제작 구조

- **시작 예시**: 우리 반 알림장, 캠프 1일차, 빈 웹앱
- **팔레트**: 안내 카드, 활동 체크, 나의 기록, 일반 버튼, AI 챗봇
- **뷰어**: 휴대폰 화면에서 웹앱 전체 구성과 결과를 바로 확인
- **컴포넌트**: Screen1 아래 구성 요소를 한눈에 확인
- **속성**: 제목, 안내, 체크 항목, 기록 문구, 버튼 동작, 챗봇 답 편집
- **블록**: 체크, 기록 저장, 일반 버튼, AI 질문의 동작 확인
- **실행**: 활동 체크, 기록 저장, 버튼, 챗봇을 실제 웹앱처럼 테스트

기본 `우리 반 알림장` 외에 `AI 캠프 1일차` 활동장과 빈 화면에서 시작하는
예제가 있습니다. 프로젝트는 브라우저에 자동 저장되며, 설정이 포함된
링크로 공유할 수 있습니다.

## 로컬 실행

Node.js 22.13 이상이 필요합니다.

```bash
npm install
npm run dev
```

검증:

```bash
npm run lint
npm test
```

기본 배포 대상은 Vercel입니다.
